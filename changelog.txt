MSE Template Packs 4.1.0 (PRERELEASE)
__MSE 2.6.4__
• Improved the update process so it should be signifigantly less likely to fail when installed on cloud storage, such as OneDrive or DropBox
• Fixed a bug that could prevent update cards scripts from occuring.
• Fixed a bug where checklists could overflow.
• The direction text style property is now scriptable.

__Other Updates__
• Added modal reminders to M15 Godzilla, fixed its notch handling, and added a style option to force the notch on.
• Added Pride Pinlines to Sagas.
• Added Star Trek keywords.

__Bug Fixes__
• DFCs: Fixed a bug where DFCs using older numbering showed the number of DFCs in your set instead of the number of cards.
• Planeswalkers: Fixed a bug where the top half of Adventure pages were invisible.
• Tokens: Fixed a bug preventing Custom Borders from applying to M20 tokens.
• Sagas: Fixed a bug where having the color indicator on caused the typeline to run over the rarity symbol.
• Sagas: Fixed legendary Class and Case creatures using the modified crown for legendary Saga creatures.
• Sagas: Moved the PT box down on the non-creature frame so it doesn't clip the rarity symbol.
• Sagas: Fixed a warning about index -1 involving the custom chapter.
• Sagas: Fixed a bug where the updated Saga coordinates weren't being saved during conversion.
• Mainframe DFC: The update script no longer makes 0,0,0,0, popouts.
• Cajun Style Emblems: The update script now applies the custom mask to the image before converting to M15 Emblems.
• Gatewatch Baseball: Fixed a bug preventing image uploads.
• Packs: Fixed the Special pack slot always being empty.
