MSE Template Packs 4.0.1 (PRERELEASE)
__MSE 2.6.1__
• Cards can now be linked to up to 32 others.
• Added settings to hide Back Face cards in the card list and having Ctrl+C and Ctrl+X also grab the back face card without needing to hold Shift.
• Added scroll bars to the windows in the Pack tab.
• Added get_link_from_cards(card, linked_card:card), which returns an array with the linked relation strings between the cards.
• Fixed an error where data subfolders with periods in them could crash the Package Manager.
• Fixed an bug where dropdown menus could go off screen on linux (thanks to amyinspace for that one).
• Fixed a crash when outlining small images.
• Improved the error message when loading a template with missing dependencies.

__New Features__
• You can now wrap text in }{ to prevent keyword matching, for example }Cycling{ will remove the }{ and prevent it from prompting <cost> or showing the reminder text.
• Added Adventure and Omen reminder texts to AUTOREM/**, and added a style option to M15 Adventures to set custom reminder text.
• The Custom Fonts module now supports 3 additional parameters for Stroke Radius (default 0), Stroke Color (default Black), and Stroke Blur (default 0).
• Added the Standard/Showcase default link for the Pack Tab updates below.

__Pack Tab Updates__
• The base rarity slots have been updated to now support Showcase frames, denoted with the Standard/Showcase card link. These slots are weighted so cards with showcases won't be more common/rare than those without; and there's a 20% chance for a card to be a Showcase instead of its Standard printing.
• Added a new card is_standard_pack_card() to determine if a card should appear in normal pack slots. By default this skips DFC back faces, tokens, cards with rarity basic land, special, or masterpiece, Showcase cards, Shifted cards, and Styling marked Promo cards.
• Additionally, this can cause DFCs, cards outside of a range of partitions, cards tagged with !nbslot, and cards tagged with one of two customizable notes to be removed from standard slots.
• Added Set Tab options Slotting Note 1 and 2. Cards who's notes include the string put here are accessible with the new "Note 1" and "Note 2" pack slots.
• Added Set Tab options Noted slotting, Nbslot slotting, and DFC slotting, which determine if cards with those notes, cards with the note "!nbslot", and DFCs are allowed in the standard slots or can only roll in the specialized ones.
• Added Set Tab option Booster partition boundaries. Default "A,A", Cards in the range of partitions will roll in standard slots.
• Added a pack type for Play Booster.
• Added pack slots for wildcards, DFCs, uncommon or rare legends, and uncommon planeswalkers.

__Template Fixes__
• M15 Mainframe: Fixed a long-standing bug where Frames and Other options checklists lagged on large set files.
• M15 Mainframe: Fixed type font color on PUMA frame.
• M15 Mainframe: Sped up the update cards script.
• M15 Adventure: Fixed update cards script not properly reversing cards.
• M15 Adventure: Fixed right-hand Omen names and types being offset too far.
• M15 Adventure: Fixed the page's indicator only working on the left side.
• M15 Saga: Fixed Replacement Chapter Folder not applying to the last chapter.
• M15 Saga: Fixed CARDNAME not working in the creature text box or last chapter ability.
• Mainframe DFC: Fixed a crash in the update cards script when a Mythic Edition Saga is converted.
• Fixed a bug where level text could be deleted or italicized when switched between frames.
• Fixed a bug where all text in the reminder cost hint was symbolized.
