MSE Template Packs 4.0: MSE 2.6, DFC Overhaul, Battles, & More (PRERELEASE)

__Automatic Updates Return!__
• This is a big, big, *big* update, so lets start with the thing that affects everyone: MSE is once again able to receive and install templates from within the client! Every few days, it will check a list of templates to see if anything needs updated and allow you to install them immediately. You can also do this manually at any time via File -> Check Updates. This will allow you to browse and install any supported template!

__DFC Overhaul__
• MSE 2.6 completely redesigns how DFCs are handled. Instead of having DFC frames, you can now link a card to up to 4 others. These links can be anything, such as tokens or cards with Partner with, but their most powerful usage is DFCs.
• You can link *any* two frames together, which means you can now make a DFC of *any* combination of frames. The display for this is slightly different, whichever card you are "focused" on will be on the left and full size, while the other face is slightly smaller on the right. You can still edit the other face's fields, just not its Style tab.
• Many frames have added support for the new "reminders" and updated "transformation" modules for proper DFC frames, including finally being able to put the transform symbol on the right side.
• You can create a DFC with Ctrl+Shift+Enter or from the add cards dropdown, which will automatically set up the DFC add-ons. You can edit or set up other kinds of links from the Cards menu.
• Existing DFC frames will update themselves to this system automatically! You don't have to change a thing!

__Mainframe Battles__
• Added the Mainframe Battles template! It took awhile but we still haven't gotten more battles yet lmao
• In addition to the standard layout from March of the Machine, I have added a "Boxed" style, which has a frame border and boxed in art like a normal card, a "Spillover" style which is that but has the art continue over the frame to the border, and a "Borderless" style which covers the entire card save the copyright area.
• The Defense symbol is not baked into the frame, and can be changed to a loyalty symbol or a PT box from the Style tab
• The template supports the Universes Beyond texture and stamps
• The template supports Nyx, Snow, Vehicle, and Custom border on the Boxed and Spillover styles.

__Station Levelers__
• With help from Aanginer, M15 Mainframe now supports Station levelers!
• By default, these will be enabled by having Spacecraft or Planet on the typeline. You can also enable it with the new Level Containers setting Station.
• You can use Stations with a normal sized art box by enabling the "de-fullart special frames" option.
• Additionally added support for Circle level container without the Station full-art or PT changes.
• As stations have semi-transparent levels, this has extended to Borderless+Fullart levelers as well.

__Prototype Support__
• M15 Mainframe and Mainframe Planeswalkers have added Prototype to their frame lists!
• This can stack with most frames, though overrides Mutate, Levelers, and Adventures.
• On M15 Mainframe, the prototype level locks to the size from BRO, and can be resized with the level offset style option.
• For planeswalkers, it automatically sizes itself on the first textbox. Be warned that this can break down if that only has one line of text in it.
• Both have a new "Prototype Secondary" option which will let you use a Type bar in place of the PT box.
• special_text() will export this textbox as "All text before reminder text <sym>Mana cost</sym> — PT|Type (Reminder text.)"

__Saga Creatures__
• The Saga frame can now do Saga Creatures and Class Creatures, with the upper and lower textboxes able to be resized however you like.
• The Chapter Coordinates settings have now been changed to Offsets, so you'll put in a number and the reminder text area, chapter divider, or type bar will move up/down that number of pixels from its usual spot.
• Saga now supports up to 6 chapter abilities, and up to 10 chapters, plus the custom chapter. The Custom Chapter will now always use the final value in Snap Chapter To Box, and will be replaced with the relevant default chapter if you don't have a custom defined.
• There is now Clear and Borderless Sagas, and you can set the opacity of the textbox, name/type plates, and outer trim for various levels of full art. 
• The Universe Beyond texture has been updated, also applying to Adventures and M15 Mainframe.

__New Adventure Frames__
• Nora3a has expanded the Adventure template for proper Omen-shaped Pages, including name-only pages. Using this on the right side covers the Prepared frame too.
• Added Borderless support to Adventures, with an option to use the original pages or the new borderless pages Glamdring uses.
• Also added support for Clear and Devoid frames, and a right chop to the right-hand Adventure page.

__Satellite Games Overhaul__
• All the Archenemy, Hero's Path, Planechase, and Vanguard frames have been collapsed into one for each game, which are part of Magic rather than individual games, so they can be mixed with standard Magic cards. Sets using those frames will need to run Convert depricated frames at https://mse-editor.neocities.org/, these will mostly not update automatically like the other frames will.

__MSE 2.6.0: Public Features__
GenevensiS and TomTkacz have been in the C++ mines making MSE sing like she hasn't in a while. Below are the new features users will see, developer updates will be at the end.
• ADDED DARK MODE.
• On Windows, fonts are now automatically loaded from any folder containing "fonts" in its name (and its subfolders) and don't need to be installed manually. Mac and Linux users will still need to install.
• Added shortcuts to apply Fonts, Font Colors, Strikethrough, and Bullet lists to any text fields.
• Added selected card count, filtered card count and total card count info to toolbar.
• Templates can now use stroke (text outlines) instead of faking it with 9 shadow copies.
• Templates can now use a slider UI for numeric fields.
• Added basic CSV / TSV / JSON importers, available from the Cards menu. Scryfall JSON files are supported. In a later update, fully customizable user written importers will be available.
• Added card linking functionality, allowing a card to link up to 4 others to be displayed at the same time when editing.
• Reinstated update checking and package manager.
• Added option to download missing stylesheets when loading a set.
• Set-level custom symbols and watermarks will now attempt to load images without needing a restart. Card-level and custom mana still need a restart.
• Added the ability to Modify Multiple Cards from the Cards menu. This lets you select any number of cards and set one of their fields to a certain value, such as changing all cards in a set to Rare.
• Exported card images now save metadata allowing you to drag and drop the exported image into any MSE file to recreate it! Sadly this doesn't work from hosts that strip metadata such as Discord.
• The art import window now has gridline options, and will remember the last crop settings used on the card instead of resetting.
• Added `update cards script`, which allows templates to update their settings or migrate to other templates.
• The stats panel now displays descriptions at the bottom on hover.
• The card list can now be sorted by up to three columns (the last three that were clicked on).
• Added an option to import/export images at a specific DPI instead of a percentage of template size.
• Added a setting to put a crude print bleed margin when exporting and printing images.
• Rewrote print layout logic so it accommodates for DFCs and different sized cards. Added cutter lines and card spacing options.
• Added option to reset a text or image field to its default state in the right click context menu and in the edit menu.
• Added more exceptions to the `english_singular` and `english_plural` script functions (thanks to halian for the list).
• <singular> and <plural> can be used in reminder text for more complicated plural terms, ex <singular>mouse</singular><plural>mice</plural>.
• MSE can now handle localization files instead of needing the user to edit it.
• Enabled card exporting from the style tab.
• Image fields using a default image will no longer display a checkerboard pattern where the image is transparent.
• Fixed a silent freeze that could occur if you opened a file and were missing templates for it.
• Fixed "referencing nonexistant file" error that could show up when undoing an image change or deletion.
• Dropdown menus will no longer be closed when a console message appears.
• Fixed the long standing set symbol rendering bug on linux (thanks to amyinspace for that one).
• Fixed various other bugs (thanks to ebbit1q, JmeJuniper and halian for their help fixing and testing).
• Improved various warning and error messages.

__Template Code Updates__
• color_background() now accepts three new parameters, artifact_blend, hybrid_blend, and multicolor_blend, which default to "mask", which behaves the same as before. Setting these to "black" will have them blend as only their respective base frame; artifact, colorless, or multicolor; without the color gradient. Setting these as "white" does the reverse, using the gradient alone and not the base cards. This allows you to skip having a dozen solid black/white images for blending, which we are rolling out to old frames as needed.
• Added the script color_multiply(color/blending_letter, image:, width:, height:, multiply_mask:@optional, iterate:@1) to apply a colored multiply effect to an image. The default intensity achieves the darker name/type bar for back face cards, and decimal intensities are allowed. An optional multiply_mask can be provided, where only the black areas of the mask will be multiplied, letting you reuse the hybrid_blend_mask in many cases.
• Added the module "reminders" for the modal dfc type/cost hints.
• Added the module "dfc" for handling DFC options like when a card counts as a back face or uses a meld bar, and makes the color dots behind transform symbols.
• Face Code is no longer necessary but will remain on the books for now.

__MSE 2.6.0: Developer Features__
• Dark Mode: Added `include dark file` token and `dark icon` property, for things that need a variant when in dark mode.
• Card Linking: Added `get_card_from_uid`, `get_cards_from_link`, `get_back_face`, `get_front_face`, `add_link`, `remove_links`, `new_uid` script functions.
• Field Properties: Added a field type "slider", which provides a slider UI.
• Field Properties: Made a few values scriptable (border color radius/left width/right width/top width/bottom width, and font shadow displacement x/displacement y/blur)
• Field Properties: Text field masks should now work with alignments other than top left.
• Field Properties: Fields with `visible:false` are no longer selectable by the user.
• Stats Properties: Added `global script` statistics dimension property. This script is run first and only once, instead of once per card like the normal script is. Its result is then available to the normal script in the `global_value` variable.
• All Packages Properties: Added `folder name` package property, available in scripts.
• All Packages Properties: Added `read only file` package property, to prevent MSE from overwriting, updating or deleting select files.
• Metadata: Added `set_metadata` and `get_metadata` script functions.
• Metadata: Added `store in metadata` image style property, to determine if the entire image is stored in the metadata, or just crop coordinates.
• Tagged Strings: Added strikethrough text format option, rendered inside the <strike> markup tag.
• Stroke: Added `stroke radius`, `stroke blur` and `stroke color` font ref properties.
• Stroke: Added `stroke radius`, `stroke blur` and `stroke color` as well as `shadow displacement x/y`, `shadow blur` and `shadow color` symbol font ref properties.
• Stroke: Added `add_stroke_effect` script function which, you're not gonna believe this, adds a stroke effect around a given image.
• Exporting: Added `get_card_export_settings` script function which returns the zoom, rotation and bleed margin set in the preferences menu.
• Importing Cards: Added `alt name` field property. The CSV / TSV / JSON importers will look for these names when parsing, to know which field to populate.
• Importing Cards: Added `import script` field property. This script will be applied to the value found in the imported file when importing via CSV / TSV / JSON, and when creating the cards with the `new_card` function.
• Importing Cards: Added `import script` game property. This script is run as the final step of the `new_card` function, to do some global cleanup.
• Update Cards: Added `update_cards_script` game and stylesheet property, which allows cards made with older versions to be updated.
• Update Cards: Added `exists_as_package` script function which checks if a given package is installed.
• Update Cards: Added `version_is_older` script function which compares two version numbers to determine which one is older.
• Image Manipulation: Added `resize_image` script function, to change an image's size.
• Image Manipulation: Added `insert_image` script function, to embed an image inside another.
• Image Manipulation: Added `dimensions_of` script function which returns the width and height of an image.
• Image Manipulation: Added `brighten_image` and `fill_image` script functions.
• Image Manipulation: Added `average`, `lightmap absolute` and `lightmap relative` combine modes.
• Image Manipulation: Added `download_image` script function to get an image from a URL. There is a user setting that may disallow all image downloads.
• Script Functions: Added `import_image` and `get_mse_path` scripts to allow MSE to load external images.
• Script Functions: Added `add_bleed_edge` script function, to add a crude print bleed edge to an image.
• Script Functions: Added `nine_slice_image` script function, to resize an image while leaving the edges untouched.
• Script Functions: Added `visibility_mask` script function, to check which pixels in an image can be seen through.
• Script Functions: Added `is_default` script function to check if the user modified a field or not.
• Script Functions: Added `stylesheet`, `stylesheet_version`, `styling_data`, `extra_data` and `notes` keys to the `new_card` function, so that these values can be populated.
• Script Functions: Added `add_card_to_set` script function, to add a card to a set (for use in the CLI).
• Script Functions: Added `make_map` script function, which takes a list of keys and a list of values, and produces a map. This allows for dynamical map initialization.
• Script Functions: Added `to_json` and `from_json` script functions, which can convert arrays, maps, cards, keywords, packs and sets.
• Debugging: The `to_json` function accepts Sets, Cards, Keywords, Packs, Styles, StyleSheets, Games and IndexMaps as input, making it a useful debugging tool.
• Debugging: The console now tries to print the value of to_json() before falling back on toCode(), to be more explicit when printing complex objects.
• Localization: Added `include localized file` token, providing support for loading localized files for more seamless localization usage.
• Localization: Localized number scripts now insert number hints.
• Colors: Added `silver` and `gold` color words, representing rgb(200,200,200) and rgb(200,180,0) respectively.
• Kerning: Symbols now get squeezed horizontally if there is not enough room for text in a single line field.
• Kerning: Spacing between symbols in a symbol font now scales with font size.
